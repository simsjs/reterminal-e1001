E1001-Calendar

E1001-Calendar is a small personal project that shows a calendar view on a Seeed reTerminal E1001 e-paper display at home. It reads the developer's own Google Tasks (read-only) to show reminders, and renders them as an image for that single display.

It is not a public service. It is used only by its developer and is not offered to other users.

Source code: github.com/simsjs/reterminal-e1001
