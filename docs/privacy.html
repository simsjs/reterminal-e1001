Privacy Policy

E1001-Calendar ("the app") is a personal project used only by its developer to display calendar information on a home e-paper display.

Data the app accesses

With the developer's permission, the app reads calendar data (event titles, times and calendar names) from the developer's own Google account through the Google Calendar API. It does not access any other person's Google data.

How data is used

Data is used only to draw the calendar screen on the developer's display. It is not used for advertising, analytics or profiling, and it is not used to train any AI or machine-learning model.

Storage and sharing

Calendar data is fetched on demand and held temporarily in memory or in a local cache on a private home server. OAuth tokens are stored on that same private server. Data is never sold, shared, or transferred to third parties.

Google API Services User Data Policy

The app's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access and deletion

Access can be revoked at any time at myaccount.google.com/permissions. Deleting the app's cache and tokens from the home server removes all data it holds.
